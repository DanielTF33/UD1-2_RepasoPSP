## 7. Ordena el ciclo de vida
   Ordena los siguientes estados de un proceso en el orden correcto de su ciclo de vida: EJECUCIÓN, NUEVO, TERMINADO, BLOQUEADO, LISTO.

Pista: el proceso nace, luego espera su turno de CPU, se ejecuta, puede quedarse esperando un recurso y finalmente muere. Repasa el punto 2.

### Solucion

Nuevo -> Listo -> Ejecucion -> Bloqueado -> Terminado
